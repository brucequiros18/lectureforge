# LectureForge Demo — Narration Script

Video: `Quiros_LectureForge_Demo.mp4` (~56 s, 1280×720).
The video already shows **two text layers**: the amber step caption at the
top and the **spoken subtitle at the bottom**. Subtitles are also saved as
`captions-narration.srt` and can be re-imported into any editor.

The current MP4 uses the built-in **male** voice (Microsoft David) as a
placeholder, timed to the subtitles below. To use your own voice, record
these eight lines, save the file as `docs/demo/voiceover.wav`, and re-run
`docs/demo/make-video.ps1` — it will use your recording automatically.

| Time | Say this (this is also the on-screen subtitle) |
|------|------------------------------------------------|
| 0:02 | This is LectureForge, my Multimedia project. It makes lecture recordings shorter. |
| 0:08 | I drop in a sample lecture. Nothing gets uploaded. |
| 0:12 | The app finds the silent parts by itself. Six gaps in this file. |
| 0:17 | Every gap is listed. I can keep one with a single click. |
| 0:23 | Now I speed it up to one and a half times. Pitch stays natural. |
| 0:28 | Then I export. It cuts, stretches, and encodes an MP3, all inside the browser. |
| 0:45 | Done. A smaller MP3, saved straight to my computer. |
| 0:50 | Offline, private, and free. Thanks for watching. |

**Tip:** when recording, read each line just as its subtitle appears, and
keep a short pause between lines so the timing stays close.

*If your teacher requires a specific format, open the MP4 in Clipchamp or
any editor to trim or re-export — the file is standard H.264 + AAC.*
